# Ритм — тренажёр печати

Простой тренажёр с чистым светлым интерфейсом. Набирайте сгенерированный текст и следите за скоростью.

- Случайные тексты на русском и английском без повторяющихся предложений.
- Раунды на 30, 60 и 120 секунд. Отсчёт начинается с первой буквы.
- Скорость в верных знаках в минуту, включая пробелы.
- Точность учитывает все введённые знаки, в том числе исправленные ошибки.
- Подсветка ошибок, новый текст и повтор текущего раунда.
- Личные рекорды сохраняются в этом браузере отдельно для каждого языка и времени.
- Перезапуск: Ctrl+Enter (Command+Enter на macOS).

## Запуск

Сайт работает на GitHub Pages из корня ветки main. Сборка и установка зависимостей не нужны.

Для локального запуска используйте любой статический HTTP-сервер, например:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000. Все вычисления и генерация текста выполняются в браузере. Внешние API не используются.
